# comsapo

**言いにくいことを、AIが“伝わる言葉”に変える。**

恋人・夫婦のすれ違いを、AIが第三者として整理するコミュニケーション支援アプリです。
AIは裁判官ではなく「翻訳者」として、発言 → 感情 → 本当のニーズ → 相手に伝わる表現 へ変換し、
「相手 vs 自分」ではなく「2人 vs すれ違い」という構図をつくります。

## 機能

| | |
|---|---|
| ログイン | メールアドレスだけのパスワードレス認証（ログインリンクは15分・1回限り） |
| ペア接続 | 招待リンク／QRコードで2人を接続。どちらからでも解消可能 |
| 話し合い | テーマごとに作成 → 個別回答 → AIヒアリング → 2人揃ったらAIが統合 → 気持ち・すれ違い・次の行動 |
| Relationship Memory | AIの保存候補のうち、**2人とも同意したものだけ**を次回以降に参照。どちらからでも削除可能 |
| 料金プラン | Free（2人で月2回）／Plus（月30回、どちらか1人の加入で2人とも利用可）。Stripe で月額課金 |
| データの権利 | 自分のデータのダウンロード、アカウント削除（関連データと有料プランも同時に削除・解約） |
| 安全 | 暴力・支配の兆候があれば安全を優先する案内を表示、相談窓口ページ |
| 法務ページ | 利用規約・プライバシーポリシー・特定商取引法に基づく表記（`public/legal/`） |

プライバシーの原則:

- 相手の回答・AIとの会話はAPIレベルで一切返さない（共有は「回答完了 ✓」の進捗と、AIが整理した結果のみ）
- 結果では生の発言を引用せず、強い言葉は感情とニーズに翻訳するよう AI に指示
- 入力内容をAIの学習に使わない（Anthropic API の商用規約上も学習に使われない）

## ローカルで試す

```bash
npm install
npm start          # http://localhost:3000
```

- `ANTHROPIC_API_KEY` を設定すると Claude が応答します。未設定ならデモモード（固定の応答）
- メール送信サービス未設定のときは、ログインリンクが画面とコンソールに表示されます
- 2人での動作確認は、通常ウィンドウとシークレットウィンドウなど別々のブラウザで

```bash
npm test
```

## 公開（商用リリース）までの手順

コードは本番用の設定と安全装置まで実装済みです。以下は**運営者のアカウントや情報が必要なため、ご自身で行う作業**です。

### 1. 外部サービスのアカウントを用意する

| サービス | 用途 | 取得するもの |
|---|---|---|
| [Anthropic Console](https://console.anthropic.com/) | AI | API キー（クレジットを購入。Console で月の利用上限も設定しておく） |
| [Resend](https://resend.com/) | ログインメール | API キー、送信元ドメインの DNS 認証 |
| [Stripe](https://stripe.com/jp) | 月額課金 | シークレットキー、Plus の価格 ID（月額のサブスク商品を作成）、Webhook シークレット |
| [Fly.io](https://fly.io/) | サーバー | アカウント（東京リージョンで常時1台＋1GBボリューム） |
| ドメイン | 公開URL | 例：comsapo.jp |

Stripe の設定:
- Webhook のエンドポイント: `https://<ドメイン>/api/stripe/webhook`
- 送るイベント: `customer.subscription.created` / `updated` / `deleted`
- カスタマーポータルを有効化（解約・カード変更をユーザー自身でできるように）

### 2. 法務ページの【要記入】を埋める

`public/legal/*.html` の黄色い【要記入】箇所（事業者名、住所、連絡先、管轄裁判所、ホスティング事業者、制定日など）。
ひな形なので、**公開前に専門家（弁護士・行政書士など）の確認を受けることを強くおすすめします**。
相談窓口ページの電話番号も、公開時点で公式サイトの最新情報と照合してください。

### 3. デプロイ（Fly.io の例）

```bash
fly launch --no-deploy            # fly.toml を使う。アプリ名は空いているものに
fly volumes create comsapo_data --region nrt --size 1
fly secrets set \
  APP_URL=https://comsapo.example.com \
  ANTHROPIC_API_KEY=sk-ant-... \
  RESEND_API_KEY=re_... MAIL_FROM="comsapo <no-reply@comsapo.example.com>" \
  STRIPE_SECRET_KEY=sk_live_... STRIPE_PRICE_ID=price_... STRIPE_WEBHOOK_SECRET=whsec_...
fly deploy
fly certs add comsapo.example.com  # 独自ドメイン
```

設定できる環境変数の一覧は `.env.example`。本番で必須の値が欠けているとサーバーは起動を拒否します。
データは SQLite（`/data/comsapo.db`）1ファイルなので、マシンは**常に1台**で動かします（`fly.toml` 設定済み）。
バックアップは Fly のボリュームスナップショット（自動・日次）に加えて、[Litestream](https://litestream.io/) で S3 互換ストレージへの継続レプリケーションを推奨します。

### 4. 公開前チェック

## AI の費用と無料枠

Claude API は従量課金です。1回の話し合い（2人のヒアリング＋統合）の概算は次のとおりです。

| | 入力 | 出力 | 費用（Claude Opus 5.5: 入力 $4 / 出力 $20 per 100万トークン） |
|---|---|---|---|
| ヒアリング 2人分 | 約 2.8万トークン | 約 0.8万トークン | 約 $0.27 |
| 統合 | 約 0.5万トークン | 約 0.5万トークン | 約 $0.12 |
| **合計** | | | **約 $0.4（60円前後）。実際は回答の長さで 40〜120円程度の幅** |

無料プランの費用は運営者の負担になるため、次の安全装置を入れています。

- `FREE_TALKS_PER_MONTH`（既定 2）: 無料プランで2人が1か月に作れる話し合いの数
- `AI_DAILY_BUDGET_USD`（既定 $20）: 1日の AI 利用額の上限。超えると翌日（UTC）まで AI を一時停止
- ヒアリングの往復数の上限、再整理の回数上限、ユーザーごとのレート制限
- 実際の利用量と概算費用は DB の `ai_usage` テーブルに記録されます

費用を下げたい場合は `COMSAPO_MODEL=claude-sonnet-5-5`（単価は約半分）も選べますが、
気持ちの「翻訳」の質に直結する部分なので、実際の会話で品質を比べてから判断してください。

## 構成

```
server/
  index.js      起動（設定検証、AI 費用ガード、終了処理）
  app.js        ルーティング（認証・ペア・話し合い・課金・データ権利）とセキュリティ
  db.js         SQLite スキーマとデータアクセス
  ai.js         Claude 呼び出し（構造化出力・フォールバック・費用計算）とデモ用モック
  prompts.js    システムプロンプト
  billing.js    Stripe（Checkout / ポータル / Webhook）
  mailer.js     ログインメール（Resend）
  config.js     環境変数
public/         ビルド不要のモバイル向け SPA、法務ページ、PWA マニフェスト
test/           API の統合テスト（モック AI）
Dockerfile / fly.toml / .github/workflows/ci.yml
```
