# comsapo

**言いにくいことを、AIが“伝わる言葉”に変える。**

恋人・夫婦のすれ違いを、AIが第三者として整理するコミュニケーション支援アプリの MVP です。
AIは裁判官ではなく「翻訳者」として、発言 → 感情 → 本当のニーズ → 相手に伝わる表現 へ変換し、
「相手 vs 自分」ではなく「2人 vs すれ違い」という構図をつくります。

## MVP でできること

| 企画のステップ | 実装 |
|---|---|
| ペア接続 | 1つのWebアプリに各自が参加し、招待リンク／QRコードで2人を Relationship として接続 |
| セッション作成 | Relationship の中にテーマごとの「話し合い」を複数作成（結婚式準備・家事・お金…） |
| STEP 1 個別回答 | 6つの共通質問に回答。下書きは端末に自動保存。相手には表示されない |
| STEP 2 AIヒアリング | 回答をもとに Claude が1問ずつ掘り下げ（最大6往復）。本人がいつでも終了可能 |
| STEP 3 統合 | 2人とも完了した時点で初めて AI が統合。各自の気持ち・本当のニーズ・感謝・共通点・すれ違いの構造 |
| STEP 4 解決策 | 誰が何をするかの具体的な行動、言い換え例、話し始めの一言 |
| Relationship Memory（簡易版） | AI が保存候補を提案 → **2人とも同意したものだけ**保存し、次回以降のヒアリング・統合で参照。どちらからでも削除可能 |

プライバシーの原則:

- 相手の回答・AIとの会話はAPIレベルで一切返さない（進捗＝「回答完了 ✓」だけ共有）
- 結果では生の発言を引用せず、強い言葉は感情とニーズに翻訳して表現するよう AI に指示
- 悪口や一時的な感情は記憶候補に含めない。保存は2人の明示的な同意が必要
- 暴力・支配・自傷他害の兆候があれば、関係修復より安全を優先する案内を結果の先頭に表示

## 起動

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 未設定ならデモモード（固定の応答）で動きます
npm start                              # http://localhost:3000
```

2人での動作確認は、通常ウィンドウとシークレットウィンドウなど別々のブラウザで開いてください。

| 環境変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | Claude API キー。未設定時はデモモード |
| `AI_MODE` | 自動 | `claude` / `mock` を強制 |
| `COMSAPO_MODEL` | `claude-opus-5-5` | 使用モデル |
| `PORT` | `3000` | |
| `DATA_FILE` | `data/db.json` | 保存先（JSONファイル） |

## 構成

```
server/
  index.js      起動スクリプト
  app.js        Express のルーティング（ペア・話し合い・ヒアリング・統合・メモ）
  ai.js         Claude 呼び出し（構造化出力）とデモ用モック
  prompts.js    システムプロンプト（翻訳者としての立ち位置・ヒアリング・統合）
  questions.js  STEP 1 の共通質問
  store.js      JSON ファイル永続化
public/         ビルド不要のモバイル向け SPA
test/           API の統合テスト（モックAI）
```

AI 呼び出しの要点:

- ヒアリング（effort `medium`）・統合（effort `high`）とも JSON Schema の構造化出力で受け取る
- `fallbacks: "default"`（beta `server-side-fallback-2026-07-01`）を有効化。安全分類器による拒否時は別モデルへ自動フォールバックし、それでも `refusal` の場合は利用者に言い換えを促す
- ヒアリングの API 履歴は追記のみ（thinking ブロックも含めてそのまま再送）。過去メモは system ではなく最初のユーザーターンに固定して埋め込む
- 統合はバックグラウンドで実行し、クライアントはポーリングで完了を検知。失敗時は再実行ボタン

```bash
npm test
```

## MVP の制約と次の一歩

- アカウントは「呼び名＋ブラウザの Cookie」だけの簡易方式。別端末でのログインやメール認証は未対応
- 保存は単一の JSON ファイル。本番運用では DB（Postgres など）と暗号化保存に置き換える
- デモモードの統合結果は定型文で、回答の一部をそのまま埋め込むだけです
